# 🔐 Cybersecurity Log Analyzer

A beginner-friendly web-based tool for analyzing sample security logs and identifying suspicious login activity.

## 🚀 Features

- 📊 Count total log events
- ❌ Detect failed login attempts
- ✅ Detect successful login attempts
- 🌐 Count unique IP addresses
- 🚨 Identify suspicious IP addresses
- 🟢 Normal / 🟡 Warning / 🔴 Critical severity levels
- 🎨 Cybersecurity dashboard interface
- 🌐 Deployed with GitHub Pages

## 🔎 How It Works

The analyzer reads sample log entries and extracts useful information such as:

- Login status
- IP addresses
- Number of failed attempts
- Number of successful attempts

If an IP address has multiple failed login attempts, the analyzer can flag it as suspicious.
